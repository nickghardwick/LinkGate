# LinkGate 0.1.4 beta

LinkGate is a macOS browser chooser for HTTP and HTTPS links.

- Choose from eligible installed browsers while preserving the incoming link.
- Set browser ordering and visibility in Settings.
- Create routing rules for URL prefixes, exact domains, or domains and their subdomains.
- Keep working through unavailable routing targets with chooser fallback and queued links.
- Download a signed and notarized universal macOS 14.0 or later beta.

This release does not yet include an in-app Sparkle updater. Updates are downloaded from the public beta release feed while Sparkle client integration is completed.
