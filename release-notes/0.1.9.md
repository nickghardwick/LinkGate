# LinkGate 0.1.9 beta

LinkGate is a macOS browser chooser for HTTP and HTTPS links.

- Adds privacy-conscious local diagnostics for link handling, browser opening, default-browser ownership, updates, and handler restoration. Diagnostics do not record browsing history or URL hostnames.
- Adds **Copy Diagnostics** to the status menu for sharing a current, sanitized app and browser-configuration snapshot with support.
- Keeps the existing browser chooser, routing rules, exact-path default-browser checks, and Sparkle update behavior.
- Download a signed and notarized universal macOS 14.0 or later beta.
