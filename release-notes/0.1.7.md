# LinkGate 0.1.7 beta

LinkGate is a macOS browser chooser for HTTP and HTTPS links.

- Updates now preserve LinkGate's default-browser registration more reliably when multiple copies of LinkGate are present.
- Continue to choose eligible installed browsers, set browser ordering and visibility in Settings, and create routing rules for URL prefixes, exact domains, or domains and their subdomains.
- Download a signed and notarized universal macOS 14.0 or later beta.
